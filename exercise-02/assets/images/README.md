# Imagen fuente

Coloca aquí un retrato/foto propio con alguno de estos nombres
(se prueban en orden, el primero que exista se usa):

```
retrato.jpg
retrato.jpeg
retrato.png
```

Mientras no exista ninguno, `main.js` dibuja una silueta de referencia
generada por código, para poder probar las tres técnicas de glitch
sin depender del archivo.
